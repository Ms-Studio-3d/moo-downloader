# Upstream and fork notes

Moo Downloader is a rebranded and modified fork of **Ezoo Download** by Ahmed Ezzat.

The upstream project declares the MIT license. The upstream copyright and
third-party notices are retained in this repository as required by that
license. Moo Downloader is not affiliated with the upstream author.

Changes in this fork include the product name, package metadata, installer
identity, local data/registry namespace, update repository, and disabling
automatic application updates until this fork has its own release-signing key.

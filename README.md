# Moo Downloader 1.0.12 Dark — نسخة محلية معدّلة

## تعديلات 23 نوفمبر 2026

- أسماء تحميلات الفيديو والصوت من إضافة المتصفح أصبحت اسم الفيديو مع الامتداد فقط، بدون إضافة الجودة أو الحجم. تظل الجودة والحجم ظاهرين في قائمة الاختيار.
- بعد اكتمال تحميل فيديو من صفحة مصدر، تُحمّل صورته المصغرة تلقائيًا بجانبه بنفس الاسم وبامتدادها الأصلي، مثل `اسم الفيديو.mp4` و`اسم الفيديو.webp` أو `.jpg`. تعمل الميزة أيضًا مع عناصر قوائم التشغيل وتحميل الصوت. لا تحتاج الصورة إلى FFmpeg، ولا يؤدي فشل تنزيلها إلى فشل الفيديو. مهلة محاولة الصورة 45 ثانية ويمكن إيقافها.
- كل تحميل جديد يظهر تلقائيًا في قائمة الجدولة الأساسية، سواء أُضيف من البرنامج أو الإضافة أو سطر الأوامر أو استيراد قائمة. تظل القائمة المخصصة المختارة محفوظة.
- «التحميل الآن» يبدأ فورًا مع مراعاة الحد العام للتحميلات، ولا يتحول تلقائيًا إلى تحميل متسلسل بسبب إضافته للقائمة. «التحميل لاحقًا» يظل متوقفًا حتى تبدأه أو تعمل الجدولة. تشغيل القائمة يحترم عدد التحميلات المتوازية المحدد لها.
- تظهر التحميلات القديمة غير المرتبطة بقائمة في القائمة الأساسية بعد فتح الإصدار الجديد، مع الاحتفاظ بأسمائها وحالتها. لا يُضاف موعد جدولة جديد.
- نافذة About من قائمة أيقونة البرنامج تعرض معلومات Moo ورقم الإصدار بدون روابط تبرع أو روابط ترويجية للمصدر الأصلي. أُزيلت أيضًا طلبات التبرع من شاشة «ما الجديد» والنافذة التلقائية بعد التحميلات.

هذه الحزمة **كود مصدري** وتحتاج بناء البرنامج لتطبيق تعديلات المحرك. بعد البناء والتثبيت، أعد تحميل إضافة المتصفح من صفحة الإضافات إذا كنت تستخدمها بوضع المطوّر. لا يكفي استبدال الإضافة وحدها لتفعيل الصور والجدولة.

الدارك هو الشكل الافتراضي للبرنامج، مع واجهة داكنة لإضافة المتصفح وقائمة الفيديو.
عند الترقية يتحول ثيم Light القديم إلى Dark مرة واحدة، ويمكن تغيير الثيم بعد ذلك
من View → Theme. اختيارات الثيمات المخصصة الأخرى تظل محفوظة.

## التحديثات

- لا يفحص البرنامج تحديثاته أو ينزّلها أو يثبتها في الخلفية.
- Help → Check for updates يفتح صفحة إصدارات Moo؛ تختار التنزيل والتثبيت بنفسك.
- تحديث yt-dlp يتم من قائمة Help فقط، مع إظهار النجاح أو الخطأ.
- تحديث FFmpeg يكون مع تثبيت إصدار جديد من البرنامج يدويًا.
- لا تُنزّل أدوات مفقودة تلقائيًا أثناء تشغيل البرنامج أو تنزيل الملفات.
- لا تتضمن إضافة Firefox عنوان تحديث تلقائي أو إضافة المطوّر الأصلية الموقّعة.

## البيانات والإضافة

تظل بيانات النسخة السابقة في %APPDATA%\Moo\MooDownloader\data،
ومعرّف المثبّت كما في Moo 1.0.0 ليكون التثبيت اللاحق ترقية لنفس التطبيق.
النسخة الجديدة تتضمن تحسينات المصدر، ومنها native messaging وFTP/FTPS
ومحرك تورنت مدمج وفحص بصمات الملفات وتحسينات الواجهة والاستئناف.

Chrome وEdge والمتصفحات المشابهة: أضف مجلد extension بوضع المطوّر.
Firefox: بدون توقيع مستقل لإضافة Moo، استخدم الخطوات المؤقتة من نافذة
إضافة البرنامج للمتصفح؛ تزال الإضافة المؤقتة عند إغلاق Firefox.

التشغيل مع ويندوز وجعل البرنامج افتراضيًا للتورنت وقاعدة جدار الحماية
اختيارات غير محددة افتراضيًا في التثبيت الجديد. قد يحتفظ المثبّت باختيارات ترقية سابقة.

## البناء والتحقق

البناء على Windows: BUILD.bat، أو GitHub Actions لإنتاج artifact.
البناء الأول يحتاج Rust وVisual Studio C++ وInno Setup واتصال إنترنت؛
سكربت BUILD يحاول تثبيت متطلبات البناء الناقصة. هذه أدوات تطوير وليست طلبات تشغيل البرنامج.
بناء FFmpeg المصغر متاح في workflow؛ البناء المحلي يحتاج ناتجه في
tools/ffmpeg/win64 للحصول على كل ميزات الفيديو.

<pre>
node scripts/check-manual-updates.cjs
node extension/test/yt-core.test.js
node extension/test/background.sim.js
cargo test -p swiftget-engine --locked
cargo build --release --locked
</pre>

هذه الحزمة مصدر معدّل؛ حالة التحقق وحدود الاختبار موجودة في REVIEW.md.

# Moo Downloader 1.0.11 — نسخة محلية معدّلة

مبنية على Ezoo Download 1.0.11 للمطوّر Ahmed Ezzat، مع هوية Moo Downloader.
اسم المطوّر الأصلي وروابط دعمه ونص الترخيص محفوظة.

## التحديثات

- لا يفحص البرنامج تحديثاته أو ينزّلها أو يثبتها في الخلفية.
- Help → Check for updates يفتح صفحة إصدارات Moo؛ تختار التنزيل والتثبيت بنفسك.
- تحديث yt-dlp يتم من قائمة Help فقط، مع إظهار النجاح أو الخطأ.
- تحديث FFmpeg يكون مع تثبيت إصدار جديد من البرنامج يدويًا.
- لا تُنزّل أدوات مفقودة تلقائيًا أثناء تشغيل البرنامج أو تنزيل الملفات.
- لا تتضمن إضافة Firefox عنوان تحديث تلقائي أو إضافة المطوّر الأصلية الموقّعة.

## البيانات والإضافة

تظل بيانات النسخة السابقة في %APPDATA%\Moo\MooDownloader\data،
ومعرّف المثبّت كما في Moo 1.0.0 ليكون التثبيت اللاحق ترقية لنفس التطبيق.
النسخة الجديدة تتضمن تحسينات المصدر، ومنها native messaging وFTP/FTPS
ومحرك تورنت مدمج وفحص بصمات الملفات وتحسينات الواجهة والاستئناف.

Chrome وEdge والمتصفحات المشابهة: أضف مجلد extension بوضع المطوّر.
Firefox: بدون توقيع مستقل لإضافة Moo، استخدم الخطوات المؤقتة من نافذة
إضافة البرنامج للمتصفح؛ تزال الإضافة المؤقتة عند إغلاق Firefox.

التشغيل مع ويندوز وجعل البرنامج افتراضيًا للتورنت وقاعدة جدار الحماية
اختيارات غير محددة افتراضيًا في التثبيت الجديد. قد يحتفظ المثبّت باختيارات ترقية سابقة.

## البناء والتحقق

البناء على Windows: BUILD.bat، أو GitHub Actions لإنتاج artifact.
البناء الأول يحتاج Rust وVisual Studio C++ وInno Setup واتصال إنترنت؛
سكربت BUILD يحاول تثبيت متطلبات البناء الناقصة. هذه أدوات تطوير وليست طلبات تشغيل البرنامج.
بناء FFmpeg المصغر متاح في workflow؛ البناء المحلي يحتاج ناتجه في
tools/ffmpeg/win64 للحصول على كل ميزات الفيديو.

<pre>
node scripts/check-manual-updates.cjs
node extension/test/yt-core.test.js
node extension/test/background.sim.js
cargo test -p swiftget-engine --locked
cargo build --release --locked
</pre>

هذه الحزمة مصدر معدّل؛ حالة التحقق وحدود الاختبار موجودة في REVIEW.md.
